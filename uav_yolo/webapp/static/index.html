📖 使用說明

這套系統在做什麼

YOLO 從空拍畫面偵測地面車輛 → 用相機參數＋雲台/機體姿態把像素換算成 GPS 座標 → Kalman 濾波估計目標位置與速度 → 對 PX4 發導引指令： 旋翼＝跟隨懸停、固定翼＝繞著目標轉圈（standoff）， 同時命令雲台持續指向目標。

🎮 第一次使用：先玩模擬模式

  1. 啟動時加參數：python run.py --sim（或設定頁把「模式」切成模擬）
  2. 儀表板會出現合成畫面與一台紅色小車，系統自動鎖定（框變綠、出現 🔒）
  3. 按「導引：關閉（點擊啟用）」大按鈕，按鈕變紅閃爍後再點一次確認 → 看俯視圖：載具開始追上目標
  4. 模擬的車在 25 秒時會急停——觀察系統怎麼收斂（這就是實戰要的行為）
  5. 到設定頁把載體切成「固定翼」→ 按「⟳ 重啟引擎」→ 看繞行行為的差異

🛫 實機任務流程

  1. 飛行前：把「任務檢查」分頁的清單全部過一遍（按「全部取消勾選」開始新任務）
  2. 起飛後由飛行員切到 Hold（AUTO.LOITER）模式
  3. 儀表板確認三綠：數傳正常、Home 已取得、模式 AUTO.LOITER
  4. 鎖定目標：等自動鎖定，或直接點「偵測列表」裡要跟的那台車
  5. 確認目標卡的速度合理、不確定度小 → 按「導引」按鈕兩次（第二次確認）啟用
  6. 系統以每秒最多 1 次發送位置指令；「未發送原因」清單隨時告訴你哪個安全閘門擋住了
🕹️ 飛行員永遠有最終控制權：任何時刻撥模式開關離開 Hold，系統立即停止發送並「閂鎖」——就算切回 Hold 也不會自己恢復， 必須回 UI 重新按啟用。這是刻意設計，防止系統在你不知情時搶回控制。

🚦 狀態燈號

搜尋中還沒鎖定目標（等自動鎖定或手動點選）
追蹤中鎖定且持續有量測，一切正常
盲區外推暫時看不到目標（繞行死角/遮蔽），用速度預測撐著，正常現象
目標丟失外推超時（預設 8 秒）已放棄，需重新鎖定

📑 四個分頁

  • 儀表板：即時影像（點偵測框可換鎖定對象）、導引開關、載具/目標狀態、俯視軌跡圖（定翼會畫繞行圓）
  • 任務檢查：任務前 to-do 清單，可自訂項目（每組最下方輸入框按 Enter 新增）
  • 系統設定：載體種類、雲台、影像來源、導引與安全參數；標 ⟳ 的改完要按「重啟引擎」
  • 相機校正：拿棋盤格對鏡頭拍 15~25 張 → 計算 → 儲存；校正過測地才準，換鏡頭/變焦後要重做

🔧 常見問題

  • 沒有畫面：設定頁確認來源選對、OBS 等程式沒佔用採集卡；看裝置清單有沒有列出你的採集卡
  • 載具卡全是「—」：數傳沒通。確認 COM 埠、鮑率（57600）、電台有沒有插好
  • 開了導引卻不動：看「未發送原因」——最常見是模式不在 AUTO.LOITER、未 arm、或還沒鎖定目標
  • 座標飄：先做相機校正；有雲台確認 PX4 MNT_MODE_IN=4 且儀表板雲台欄顯示「有回報」
  • 定翼繞太大/太小圈：UI 繞行半徑與 PX4 NAV_LOITER_RAD 要設一樣的值
